Hi, I'm Javier Garrido.

I'm a web developer based in Burgos, Spain, working remotely for Kodify Media Group. Most of my career has been on the backend, mainly with Node.js, and I'm at home on the frontend with React too. Before JavaScript took over, I built things with .NET.

These days I care a lot about how software is designed: domain-driven design, system architecture and the decisions that are hard to undo later. I like teams where people learn from each other, and I try to be the one who raises a hand when something needs doing.
